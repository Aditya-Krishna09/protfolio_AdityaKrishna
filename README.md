# Aditya Krishna — Portfolio Website (V2)

A responsive, cinematic-light portfolio built with plain HTML, CSS, and JavaScript. No package installation or build step is required.

## Preview locally

1. Unzip the project folder.
2. Open a terminal inside `aditya_krishna_portfolio`.
3. Run `python3 -m http.server 8000`.
4. Visit `http://localhost:8000`.

## Structure

- `index.html` — main portfolio homepage
- `styles.css` — design system, animation, responsive layout, and case-study styles
- `script.js` — homepage interactions, filters, scroll reveals, and interactive hero parallax
- `case-study.js` — case-study page interactions
- `work/` — six dedicated case-study pages
- `assets/` — supplied images and the Alchenova participation certificate

## V2 improvements

- Layered, pointer-reactive 3D-style hero sculpture and orbital scene
- Floating parallax details and scroll-responsive hero movement
- Chapter navigation rail on desktop
- Dedicated case-study pages for HotelSarthi, Krishna Palace, Akshayakalpa, Parivartan, AUREON Mobility, and Project Second Shift
- Case-specific metrics, process, deliverables, outcomes, and careful assumptions/disclaimers
- Reduced-motion support and mobile layouts

## Accuracy & exclusions

- HotelSarthi is described as connected with 7 hotels.
- Akshayakalpa's 10,000 L/day figure is a proposal target; the team was selected among 10 finalist teams.
- Parivartan's 2 GWh pilot and financial model are proposals/illustrative assumptions, not committed capital or an implemented project.
- AUREON Mobility is a fictional case company; assumptions are labelled.
- Project Second Shift is shown as an individual submission; the certificate confirms participation, not ranking.
- Alchenova is presented as participation only.
- Confidential case decks are not publicly embedded or linked.
- Protean chatbot visuals, WhatsApp automation visuals, and GitHub project links are intentionally excluded.
- No public phone number or personal email address is published.

## Publish with GitHub Pages

This repository is configured for GitHub Pages from the `main` branch root. Keep `index.html` at the repository root and preserve the `assets/` and `work/` directories. The project also contains the separate scroll-animation demo under `scroll-animation-site/`.
